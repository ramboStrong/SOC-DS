# SOC-DS

Materials for **SOC-DS: Distance-Stratified Space Density Estimation for Ground-Based Optical Space-Object Population Assessment**.

- `src/`: A0--A6, training, and testing
- `label_generation/`: input and label construction
- `partition/`: distance-partition sensitivity
- `analysis/`: statistical and diagnostic analyses
- `checkpoints/FILES.txt`: A0 checkpoint filenames
- `configs/official_protocol.json`: experimental settings
- `data/ACCESS.md`: frozen-corpus access
